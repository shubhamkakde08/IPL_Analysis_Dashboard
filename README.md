# 🏏 IPL Analysis Dashboard (2008–2025)

An interactive data analytics dashboard built to analyze **Indian Premier League (IPL)** performance across seasons, teams, and players. This project transforms raw match and player data into meaningful visual insights using business intelligence techniques.

---

## 📊 Project Overview

This dashboard delivers a complete performance breakdown of IPL seasons from **2008 to 2025**, highlighting:

- Season winners and runner-ups  
- Orange Cap (Most Runs) and Purple Cap (Most Wickets) leaders  
- Team-wise points table analysis  
- Total sixes, fours, matches, venues, and centuries  
- Player dominance trends and team performance comparisons  

The objective of this project is to demonstrate **data visualization, sports analytics, and storytelling with data**.

## 🔍 Key Insights

- Punjab Kings and Royal Challengers Bangalore finished with equal wins, with ranking influenced by additional match factors  
- B Sai Sudharsan led the season with outstanding batting consistency  
- Gujarat Titans players dominated boundary statistics (fours and overall runs)  
- Lucknow Super Giants showcased strong six-hitting performance  
- Mid-table competition highlights the increasing balance in league performance
